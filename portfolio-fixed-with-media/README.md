# Efad Sarkar Portfolio

Static portfolio built with HTML and CSS. No framework, build step, external font, analytics script or JavaScript library is required.

## Deploy

Copy the contents of this folder into the root of the GitHub Pages repository. Keep the `projects/` and `assets/` folders alongside `index.html`.

## Included

- `index.html`: responsive portfolio home page with category filters.
- `projects/`: 25 individual project case-study pages.
- `assets/project-atlas.webp`: one shared, compressed media atlas used by the project cards and galleries.
- `sitemap.xml`, `robots.txt`, `404.html`: basic site discovery and fallback pages.

## Performance

The site uses inline CSS, small static HTML pages and one shared WebP media file (about 100 KB). It does not load external libraries or large video files. Project videos are not embedded; this keeps the first page load light.

## Project accuracy

Each case study separates the problem, implementation, workflow steps, practical value and current evidence/status. Prototype and demo-only work is labelled as such.
