Telegram Voice and Text Assistant

Telegram assistant that handles text and voice messages with transcription, AI responses and memory.

Workflow screenshotPersonal assistant13-node workflow

The problem

Switching between voice notes and text messages can interrupt a simple assistant workflow, and users may need a conversational history for follow-up questions.

What I built

The workflow accepts Telegram text or voice input, transcribes audio, generates a response and can return a spoken reply using connected AI services.

How the workflow works

  1. A user sends text or a voice note in Telegram.
  2. Voice input is transcribed through the configured speech service.
  3. The AI model generates a response using the available conversation context.
  4. The assistant returns text and, where configured, generated audio.

How it helps

It provides one interface for text and voice interaction and demonstrates speech-to-text plus text-to-speech orchestration.
